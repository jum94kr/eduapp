# Phonics Cluster Map

## Foundations
- Short vowels: `a e i o u`
- CVC families: `-at, -an, -it, -op, -ug`

## Consonant Blends
- S-blends: `sn, sm, st, sp, sk`
- L-blends: `bl, cl, fl, gl, pl, sl`
- R-blends: `br, cr, dr, fr, gr, tr`

## Digraphs
- Core: `sh, ch, th (voiced/unvoiced), wh, ck, ng, ph`

## Long Vowel Patterns
- Silent-e: `a_e, i_e, o_e, u_e`
- Teams: `ai, ay, ee, ea, oa, ie, oi, oy`

## R-controlled
- `ar, or, er, ir, ur`

## Sequencing Principles
- Introduce one primary + one review cluster per questline.
- New cluster appears in audio-first scene before text-heavy tasks.
- Progression gates use rolling mastery, never one-shot test success.
